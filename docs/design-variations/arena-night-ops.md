# Arena Night Ops

High-contrast night arena cockpit with neon status cues and fast-glance operational hierarchy.

## UX direction
- Applies a distinct global visual system through `src/index.css`.
- Adds a visible variation strip in `AppShell` so reviewers can immediately confirm which branch they are viewing.
- Keeps data flows and routes unchanged so this PR can be evaluated as an isolated design/UX concept.
